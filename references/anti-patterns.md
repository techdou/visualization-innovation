# Visualization Innovation Anti-Patterns

- **Novelty theater:** unusual form, no task advantage.
- **Chart roulette:** swap one standard chart for another without reframing the relation.
- **Radial reflex:** circular layout only because it looks researchy.
- **3D reflex:** depth without a spatial/volumetric reason.
- **Channel overload:** too many visual channels in one glyph.
- **Dashboard collage:** many views, no shared state/evidence chain.
- **Interaction garnish:** hover/animation presented as analytical innovation.
- **Story afterthought:** explanatory prose appended to charts and called storytelling.
- **Paper mimicry:** copy another paper’s panel structure and change labels/data.
- **AI magic box:** generated visualizations with hidden transformations/provenance.
- **Embedding truth fallacy:** 2D projection treated as real high-dimensional structure.
- **Animation masks comparison:** movement prevents exact before/after judgment.
- **Innovation without baseline:** no conventional solution/failure mode identified.
- **Innovation without evaluation path:** “better insight” with no way to test or substantiate it.
