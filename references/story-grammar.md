# Visualization Story Grammar

Story is a designed path through evidence, not prose appended to a chart.

## Exploratory story
`Question → Explore → Surprise → Verify → Compare → Explain → Next question`

## Explanatory story
`Context → Claim → Evidence → Contrast → Explanation → Qualification → Takeaway`

## Hybrid story
Guided spine + optional exploration + clear return path.

## Figure story
`Orient → Focus → Compare → Explain → Takeaway`

## Interaction story
`Cue → Action → Visual response → Evidence → Interpretation → Next action`

## System story
`Input → Transformation → Representation → Interaction → Update → Outcome`

## Story atom
**Context → Cue → Action/Transition → Evidence → Interpretation → Next Question**

## Narrative devices
Callout anchored to a data fact; progressive reveal; meaningful annotation; view transitions; highlight/dim/restore; small-multiple scenes; timeline/storyline; before/during/after; counterexample/uncertainty scene; recap/bookmark state.

## Author-driven vs reader-driven
Treat as a continuum. Decide how much the author controls order versus how much the reader explores. Preserve a return path to the narrative spine.

## Stateful story principle
Prefer story steps that are real visualization states rather than screenshots. This enables branching, replay, provenance, comparison, and editable tours.

Bind consequential scenes to data/state/computation versions, observations and alternative explanations using `references/evidence-story.md`. Export the same evidence into the interactive scene, Figure and caption.
