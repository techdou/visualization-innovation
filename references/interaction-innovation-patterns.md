# Interaction Innovation Patterns

Describe important interactions as:

**Intent → Trigger → Target → State Transformation → Feedback → Consequence**

## Direct manipulation
Manipulate analytical objects such as anchors, centroids, thresholds, partitions, constraints, paths, or time windows.

## Semantic brushing
Select by meaning rather than geometry: same class, rule coverage, uncertainty regime, temporal episode, community, or explanation pattern.

## Interaction composition
Inspired by Libra/Libra+: compose parameterized primitive interactions and resolve trigger/target/feedback conflicts.

## Lens + local transformation
A movable region reveals density, uncertainty, raw samples, alternate scale, neighboring edges, or higher-resolution data.

## Parameter steering
Couple a control to immediate evidence of what changed, not only a new final chart.

## Branchable history
Treat important states as nodes. Branch from prior states and compare alternatives rather than overwriting them.

## Interaction-contingent feedback
Inspired by JuicyVIS: design feedback timing, locality, persistence, and intensity. Feedback must clarify state/consequence first.

## Distortion-aware interaction
If a representation is approximate, interaction should expose reliability or instability rather than treat the projection as ground truth.

## Demonstration-to-authoring
Capture an interaction sequence and transform it into an editable story/analysis script, as in the broader principle behind DashGuide.

For important cross-view actions apply `references/coordination-contract.md`: specify typed selection, mapping, population, invariant reference, undo, and async version policy.
